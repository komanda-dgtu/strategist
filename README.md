# Стратег Фабрики продуктов

_Команда ДГТУ · MGIMO AI Challenge × МегаФон, задание «Стратег Фабрики продуктов», 2026._

ИИ-агент для руководителя цифрового продукта: от размытого запроса — к проверяемой картине
ситуации, трём и более вариантам и согласованной продуктовой и коммуникационной стратегии.
После решения агент следит за обязательствами и пересматривает выводы при новых данных.

## Что нужно
- **[Cursor](https://cursor.com)** — основная среда (платный тариф: агенту нужно много запросов).
  Работает и в Claude Code — см. «Другие среды» ниже.
- **Python 3.9+.** Только стандартная библиотека, ставить пакеты не нужно.
  Проверка на Mac: Терминал → `python3 --version`. Если macOS предложит установить
  «инструменты командной строки» — согласитесь, это и есть Python.
- **Интернет** — для поиска по открытым источникам. Платных API и ключей не требуется.

**Готовый пример.** `projects/megakino-retention/output/00-passport.md` — паспорт решения учебного кейса
«удержание подписки МегаКино»: вопрос → проверенные факты и гипотезы → варианты, включая «как есть»
и «закрыть», с возражениями → выбранная связка, расчёт порогов окупаемости и решения с условиями пересмотра.
Второй пример другого типа — `projects/podpis-nomera/` («кому предлагать „Подпись номера“ и что сказать»,
экспресс-режим за одну сессию). Замеры: сравнение с обычным чатом — `bench/result.md`, каскад дешёвой и
основной модели для массовой разметки — `bench/cascade/README.md`.

## Первый запуск (Mac, Cursor)
1. Скачайте репозиторий (кнопка Code → Download ZIP) и распакуйте, например, в папку `Курсор`.
2. В Cursor: **File → Open Folder…** → выберите папку `strategist`.
   Именно её, а не папку уровнем выше: Cursor берёт хуки (`.cursor/hooks.json`), субагентов и правила
   из корня открытой папки. Если открыть родительскую папку, хуки молча не запускаются и расходы не считаются.
3. Если Cursor спросит, доверять ли проекту и запускать ли его хуки, — разрешите
   (хуки нужны для продолжения после перерыва и учёта времени; их код — в `hooks/` и `scripts/`).
4. Откройте чат агента (**⌘ I** или **⌘ L**) и напишите задачу, например:
   > Почему падает удержание подписки на онлайн-кинотеатр и что с этим делать?

Агент сам создаст проект, задаст 2–3 уточняющих вопроса и пойдёт по этапам.
Этапы можно вызывать и вручную: введите `/` в чате и выберите
`start`, `frame`, `gather`, `research`, `options`, `strategy`, `decide`, `revise`.

**Перерыв.** Закройте чат или Cursor в любой момент. В новом чате агент сам покажет,
где остановились и что предлагает дальше.

**Вмешаться.** Остановите агента, уточните задачу или скажите, что исправить —
например, «вариант O3 не подходит, у нас нет бюджета на разработку». Исправление
записывается в реестр, агент показывает, какие выводы оно задевает, и пересматривает только их.

**Проверить, что всё на месте** (в терминале Cursor, **⌃ `**):
```
python3 scripts/ledger.py list        # проекты; демо по умолчанию — projects/DEFAULT
python3 scripts/ledger.py use megakino-retention   # открыть демо явно
python3 scripts/ledger.py validate    # проверка реестра активного проекта
python3 scripts/passport.py           # паспорт решения
```

## Где результат
`projects/<кейс>/output/`:
- **`00-passport.md` — паспорт решения: одна страница для руководителя** (рекомендация,
  варианты с силой оснований, критические неизвестные, следующий шаг, что менялось)
- `01-brief.md` — постановка задачи
- `03-situation.md` — картина ситуации: что известно, откуда, чего не знаем
- `04-options.md` — варианты и возражения
- `05-strategy.md` — продуктовая и коммуникационная стратегия, план проверки
- `06-decisions.md` — решения, ответственные, условия пересмотра
- `evidence.md` — все утверждения с метками и источниками
- `costs.md` — время агента и человека, стоимость

## Другие среды
- **Claude Code:** `cd strategist && claude`. Правила подключаются через `CLAUDE.md`,
  хуки — `.claude/settings.json`, токены считаются автоматически.
- **Codex, OpenCode и др.** читают `AGENTS.md`; скрипты — обычный Python.

## Ключевые решения
1. **Реестр утверждений** (`scripts/ledger.py`). Каждое сведение — запись с типом
   (факт / гипотеза / прогноз / синтетика / ввод пользователя / вывод), источником и статусом.
   Стратегия собирается из реестра, поэтому любой тезис раскрывается до источника,
   а при новых данных `ledger.py impact` показывает, какие выводы пересмотреть.
2. **Валидатор** проверяет: у фактов есть реальные источники; ни один вывод не держится
   только на синтетике; вариантов ≥3 и есть «как есть» и «закрыть»; у каждого варианта
   есть возражение; каждое обещание коммуникации опирается на элемент продукта;
   у решений есть ответственный, показатель и условие пересмотра.
3. **Раздельные знания**: правила (`AGENTS.md`), методика (`method/`), материалы
   (`projects/*/sources`, `ledger.json`), состояние (`projects/*/state.md`).
4. **Субагенты** в отдельном контексте и в режиме только чтения: `researcher` (поиск), `red-team`
   (возражения — не защищает собственные варианты), `auditor` (сверка с источниками), `persona`
   (модельные респонденты, всегда с меткой СИНТЕТИКА), `classifier` (массовая разметка на дешёвой модели).
5. **Хуки** (`.cursor/hooks.json`, `.claude/settings.json` — Cursor читает оба): восстановление
   контекста при старте сессии, защита от команд в источниках, учёт токенов и модели после каждого
   ответа агента (`costs/cursor-turns.jsonl`).
6. **Сила оснований.** Валидатор считает, какая доля опор каждого варианта — факты или ввод руководителя, и называет
   гипотезы, на которых вариант держится напрямую. Это отделяет «красиво обосновано» от «проверено».
7. **Паспорт решения** (`scripts/passport.py`) — одна страница из реестра. Критические
   неизвестные ранжируются по тому, сколько выводов от них зависит.
8. **Гипотезы проверяются, а не копятся** (`ledger.py verify`): итог «подтверждена / опровергнута /
   частично / данных не хватило» записывается только с источником; опровергнутая гипотеза
   подсвечивает всё, что на ней держится.
9. **Устаревшее заменяется, а не теряется** (`ledger.py supersede`): свежий факт встаёт на место
   старого, связи переводятся, а агент получает список выводов, которые надо перечитать по смыслу.
   Так 13.11 свежие цены изменили вывод K1 → K7 в учебном кейсе.
10. **Расчёт вместо слов** (`projects/<кейс>/model.py`): без внутренних данных агент считает пороги
   окупаемости вариантов; паспорт подхватывает итог сам.
11. **Устойчивость к сбоям.** Запись реестра атомарная; повторная запись того же утверждения или
   источника не создаёт дубль — после сбоя шаг можно безопасно повторить.

## Авторство и лицензии
- **Riskiest Assumption Test** — термин Рика Хайэма (Rik Higham, 2016).
- Методы в `method/` — общепринятые практики со ссылками на авторов в `method/00-toolkit.md`.

- Код и инструкции агента (`AGENTS.md`, `.claude/`, `scripts/`, `method/`) — Команда ДГТУ.

## Безопасность
Только открытые данные. Ключи — в переменных окружения, `.env` в `.gitignore`.
Текст источников — данные, а не инструкции.

## Переносимость
Правила — в `AGENTS.md` (читают Cursor, Codex, OpenCode и др.), `CLAUDE.md` подключает его для
Claude Code. Навыки — в `.claude/skills/` (Cursor читает эту папку). Субагенты: исходник —
`.claude/agents/`, копия для Cursor — `.cursor/agents/` (`python3 scripts/sync_agents.py`).
