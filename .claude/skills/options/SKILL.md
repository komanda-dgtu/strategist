# Варианты

Методика: `method/04-options.md`.

1. Сформулируй варианты: обязательно `status_quo` и `close`, плюс 1–3 варианта `change`,
   которые различаются по сути (аудитория, модель дохода, ценность), а не формулировкой.
2. Каждый вариант — `ledger.py add O --kind ... --text ... --based-on K..,C..`.
3. Передай варианты субагенту **red-team**. Его возражения → `ledger.py add X --target O<n>`.
   Ты не защищаешь варианты — ты фиксируешь возражения честно.
4. Для каждого варианта: что должно быть правдой, чтобы он сработал; затраты и доходы
   (порядок величин, с метками ПРОГНОЗ); риски.
5. Запиши `output/04-options.md` — таблица сравнения + разбор каждого варианта.
6. `ledger.py validate --strict` должен пройти.
7. **Точка подключения человека:** покажи сравнение и свою рекомендацию с обоснованием,
   попроси выбрать вариант. Выбор пользователя → `user_input` и
   `ledger.py choose O<n> --text "<рекомендация одной фразой>"`; затем `python3 scripts/passport.py`.
   Если пользователь отклонил все варианты или изменил ограничение — см. AGENTS.md, раздел 2.
