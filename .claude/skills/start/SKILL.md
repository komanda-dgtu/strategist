# Старт или продолжение

1. Посмотри проекты: `python3 scripts/ledger.py list`.
2. Если пользователь хочет продолжить — `ledger.py use <имя>`, прочитай `projects/<имя>/state.md`
   и продолжай с текущего этапа (см. AGENTS.md, раздел 4).
3. Если это новая задача:
   - придумай короткое латинское имя папки (`wallet-retention`);
   - `python3 scripts/ledger.py new <имя> "<запрос дословно>"`;
   - запиши дословный запрос как `user_input`:
     `ledger.py add-source --title "Запрос пользователя" --kind user --file state.md`
     и `ledger.py add C --type user_input --text "<запрос>" --sources S1`;
   - спроси одним вопросом режим: **полный** (этапы по порядку, несколько сессий) или
     **экспресс** (одна сессия 30–40 минут, черновик паспорта со списком непроверенного —
     AGENTS.md, раздел 2). Запиши выбор в `state.md`;
   - переходи к навыку `/frame`.
4. Скажи пользователю в 2–3 строках: что за проект, какие будут этапы, где он сможет вмешаться.
