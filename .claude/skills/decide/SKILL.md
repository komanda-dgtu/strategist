# Поддержка решений

1. Для каждого решения: `ledger.py add D --target O<n> --text ... --owner ... --metric ...
   --review-if "<условие>" --review-date YYYY-MM-DD --based-on ...`.
2. `ledger.py validate` покажет решения, у которых подошла дата пересмотра, и решения,
   чьи основания оспорены или отозваны.
3. Пересобери паспорт: `python3 scripts/passport.py`.
4. Запиши `output/06-decisions.md`: список решений, **что решать сейчас**, **какие основания устарели**
   (по предупреждениям валидатора и датам источников старше 6 месяцев).
