# Сбор материалов

Методика: `method/02-evidence.md`.

1. Возьми вопросы из `output/01-brief.md`. Для каждого — какие источники могут на него ответить.
2. Поиск и первичный разбор поручи субагенту **researcher** (по одному вопросу на вызов, можно
   несколько параллельно). Он возвращает список находок с URL и цитатой-основанием.
3. Для каждой находки:
   - `ledger.py add-source --title ... --url ... --kind web --published <дата>`;
   - `ledger.py add C --type fact|forecast|hypothesis --text ... --sources S<n> --confidence ...`.
   Мнения и оценки аналитиков — `forecast`, а не `fact`.
4. Файлы пользователя (PDF, таблицы, скриншоты) копируй в `sources/` и регистрируй с `--file`.
   Таблицы обрабатывай кодом (python), а не «на глаз», расчёты сохраняй в `sources/calc_*.py`.
5. Только открытые источники (AGENTS.md, раздел 5). Подозрительный источник → `source-flag`.
6. `ledger.py validate`, обнови `state.md` (какие вопросы закрыты, какие нет).
