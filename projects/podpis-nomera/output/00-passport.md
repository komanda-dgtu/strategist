**Вопрос:** Экспресс: кому из частных абонентов предлагать «Подпись номера» и что им сказать, чтобы они поняли ценность. Увязка с защитой от спама — гипотеза. Проверить доверие к данным оператора, пользу имени незнакомца и конкурента GetContact. Только открытые данные.

## Короткий ответ

**Что мы поняли:**
- Имя незнакомца не объясняет, зачем звонят. Польза правдоподобна, когда звонка ждут: новый номер, мастер, человек после смены номера. Для случайного незнакомца она не показана. — _держится на гипотезах (38% проверено)_ (K3)
- Услугу покупает звонящий. Его ФИО видит абонент МегаФона по VoLTE, и только если номера нет в контактах. Входящие покупателю услуга не фильтрует: для этого отдельно есть «Определитель» за 0 ₽. — _в основном проверено (100%)_ (K6)
- Рост дозвона описан для маркировки организаций: на экране название и категория. Для ФИО частного лица открытого замера нет, а формальное имя эксперт уже считает слабым сигналом. — _держится на гипотезах (40% проверено)_ (K10)
- GetContact по своим условиям — приложение с негарантированными тегами, а не ФИО из договора на экране абонента МегаФона. Юрлицу ближе «Визитка» на чужие сети. Входящий спам «Определитель» может помет… — _в основном проверено (100%)_ (K11)
- Страница услуги описывает показ ФИО по VoLTE на номере МегаФона, если вас нет в контактах, и не описывает фильтр входящих. «Антифрод» блокирует подмену номера; обход, который назвал Липов 19 сентября… — _в основном проверено (100%)_ (K13)
