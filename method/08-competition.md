# Конкурентная среда

## Кого считать конкурентом
1. Прямые — такие же продукты (подписки-агрегаторы других операторов, экосистем).
2. Альтернативы по задаче (JTBD) — что ещё пользователь «нанимает» для той же задачи:
   прямая подписка на один сервис, экосистемная подписка, бесплатный контент, пиратство, «ничего».
3. Поставщики — если продукт собран из чужих сервисов, они одновременно партнёры и конкуренты.

## 5 сил Портера (кратко, только если оцениваем привлекательность направления)
Сила поставщиков (кинотеатры), сила покупателей, угроза заменителей, барьеры входа, соперничество.
Для каждой силы — вывод «высокая/средняя/низкая» со ссылками на C.

## PESTEL
Только факторы, которые меняют решение (регулирование, платежи, доступность сервисов). Остальное не пишем.
