# Customer Journey Map

Строится по фактам: каждая точка пути ссылается на источник (скриншот, отзыв, описание условий).
Догадки о чувствах пользователя — гипотезы.

## Этапы (для подписочных сервисов)
Узнал → Понял, что это → Подключил → Первый просмотр (момент ценности) → Привычка →
Списание / продление → Отказ или возврат.

## Для каждого этапа
| Поле | Пример |
|---|---|
| Что делает пользователь | Выбирает кинотеатр внутри подписки |
| Точка контакта | Приложение оператора, сайт, приложение кинотеатра |
| Что видно (факт, источник) | Нужна отдельная активация в каждом сервисе [S7] |
| Барьер / боль | Непонятно, где смотреть фильм |
| Сигнал в данных | Жалобы в отзывах, доля неактивных подписок (пробел) |
| Метрика этапа (HEART) | Adoption, Retention, Task success |
